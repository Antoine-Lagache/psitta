# 📘 Flutter App Langue

Un projet d’application Flutter pour l’apprentissage des langues.  
C’est mon premier projet Flutter, il sert à la fois d’exercice pour apprendre le langage **Dart** et le framework **Flutter**, et de base pour une vraie application.

---

## 🚀 Objectifs

- Développer une application Flutter multi-plateformes (Android, iOS, Web, Desktop).  
- Mettre en place un plan d’apprentissage progressif (MVP → version avancée).  
- Découvrir et appliquer les bonnes pratiques de développement logiciel.
