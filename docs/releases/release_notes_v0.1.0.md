First public version of Psitta, an open-source Japanese study application.

- 1,297 words and 1,380 sentence groups containing 3,452 sentences.
- Furigana, English meanings and translations, and source attribution.
- Spaced repetition, sentence practice, resumable sessions and activity statistics.
- Local learning progress; the bundled corpus contains no audio.

## Downloads

- Windows x64: run the `setup.exe` installer. A portable ZIP is also provided.
- Ubuntu 24.04 amd64: install the `.deb` with `sudo apt install ./psitta_0.1.0-2_amd64.deb`.
- Android: install the APK. Updates must use the same signing key; a development
  installation using another key cannot be updated directly by this release.

Windows binaries are unsigned and may trigger SmartScreen. The Ubuntu package
is not guaranteed to support other distributions. macOS and iOS are not included
as supported platforms. Builds have been exercised on the maintainer's devices,
not certified across all OS/device versions.

Learning content is frozen with documented editorial limitations. Source
translations are retained where flagged; alternative suggestions are explicitly
labeled. This is a study aid, not a complete Japanese course.

There is no automatic application update, cloud sync or user-facing progress
backup. Existing populated databases are not replaced with a new bundled corpus.
