# Idée pour l'appli
**Les idées ne sont pas dans l'ordre**

0) Une UI plutot clean, fonctionnalité de base de naviguation *OUI*
1) Pouvoir créer une session de type Word ou de type sentence. L'UI affiche avant le début de la session le nombre d'exercice à réviser  et de nouveau exercice. *OUI*
2) Option pour ne faire qu'une partie de la session. Avant la création de la session, l'Utilisateur peut choisir de faire par exemple 40% des exercices et une sessions est créer avec 8 exercices au lieu de 20 (par exemple). Cela permet de ne pas s'arreter au milieu d'un exercice. *OUI*
3) Petit message sur le menu principal disant s'il reste des choses à réviser/ apprendre pour aujourd'hui *OPTIONNEL MVP*
4) Dans le menu statistique : stats du jours ou de la dernière session avec évidement stats général / global (inspiré d'Anki) *OUI mais vite fait*
5) Dans les paramètre : il y a les paramètre généraux (hors session). Mais il doit aussi y avoir des paramètre des sessions (SRSConfig). On peut modifier la config par défaut, config par type de session, par type de langue (mais il n'y a qu'une seule langue en MVP ??), et config pour aujourd'hui. *OUI mais ne pas trop surchargeer les paramètres/ rester simple*
6) Pendant une session : bouton quitté la session (avant la fin). *OUI*
