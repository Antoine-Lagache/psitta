# 🧪 Dossier `playground/`

---

## 🎯 Rôle du dossier

Le dossier **`lib/playground/`** regroupe divers fichiers de test et d’expérimentation réalisés au cours du développement.  
Il sert d’espace libre pour :
- expérimenter des concepts **Dart / Flutter** sans impacter le code principal ;
- tester des classes, des fonctions ou des algorithmes avant intégration ;
- conserver des exemples pédagogiques de syntaxe ou de logique Flutter.

---

## 📁 Contenu actuel

| Fichier | Description |
|----------|--------------|
| `default.dart` | Premier fichier d’exploration, contient des tests simples de syntaxe Dart. |
| `exo1.dart` / `exo1_cor.dart` | Exercices pratiques d’introduction à Dart, avec leurs corrections correspondantes. |
| `exo2.dart` / `exo2_cor.dart` | Deuxième série d’exercices de programmation, plus avancée (structures, boucles, etc.). |
| `exo_menu.dart` | Essais autour des widgets Flutter et navigation basique entre écrans. |

---

## 🧩 Bonnes pratiques

- Ce dossier n’est **pas inclus dans la version de production** de l’application.  
- Il peut être utilisé pour de futurs **prototypes rapides**, par exemple tester un nouvel écran ou une nouvelle logique SRS.
- Les fichiers obsolètes ou purement exploratoires peuvent être archivés dans `playground/old/` si besoin.
