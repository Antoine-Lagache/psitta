Psitta 0.1.1 improves the study experience and fixes several issues in the first release.

- Keep learning actions visible at the bottom of the screen, even when exercise content is long.
- Select and copy Japanese exercise text for external lookup.
- Show fractional SRS review intervals with readable units.
- Use four visible grading buttons: Again, Hard, Good and Easy. Existing grade history is preserved.
- Improve sentence selection within related sentence groups and remaining training counters.
- Correct the date filtering for completed-session statistics.
- Improve session transitions when pausing, ending or continuing.
- Add a developer About page and refresh website navigation.

## Downloads

- Windows x64: use the setup installer or portable ZIP.
- Ubuntu amd64: install the DEB package or use the portable archive.
- Android: install the APK. Updating an existing installation requires the same signing key.

Windows binaries are unsigned and can display security warnings. macOS and iOS builds remain experimental and are not supported device-tested releases.

Learning progress stays on your device. No cloud sync, in-app backup or automatic updates are available yet. Existing populated databases are not replaced with the bundled corpus.
