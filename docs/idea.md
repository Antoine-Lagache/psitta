# Idée pour l'appli
**Les idées ne sont pas dans l'ordre**

0) Une UI plutot clean, fonctionnalité de base de naviguation
1) Pouvoir créer une session de type Word ou de type sentence. L'UI affiche avant le début de la session le nombre d'exercice à réviser  et de nouveau exercice.
2) Option pour ne faire qu'une partie de la session. Avant la création de la session, l'Utilisateur peut choisir de faire par exemple 40% des exercices et une sessions est créer avec 8 exercices au lieu de 20 (par exemple). Cela permet de ne pas s'arreter au milieu d'un exercice.
3) Petit message sur le menu principal disant s'il reste des choses à réviser/ apprendre pour aujourd'hui
4) Dans le menu statistique : stats du jours ou de la dernière session avec évidement stats général / global (inspiré d'Anki)
5) Dans les paramètre : il y a les paramètre généraux (hors session). Mais il doit aussi y avoir des paramètre des sessions (SRSConfig). On peut modifier la config par défaut, config par type de session, par type de langue (mais il n'y a qu'une seule langue en MVP ??), et config pour aujourd'hui.
6) Pendant une session : bouton quitté la session (avant la fin).

### Idée pour le futur:

7) Pouvoir voir la définition d'unn mot dans une phrase en appuyant dessus.
8) Pouvoir apprendre plusieurs langue
9) Pour les langues concerné, avoir un type de session permettant d'apprendre des nouveau charactère : apprendre à lire les charactère, mais aussi s'entrainer à les écrire. (pour l'écriture, une zone de dessins suffit pas besoin de fonctionnalité complexe)
10) Un menu permettant de voir la liste des mots / phrases appris et la listes de futur mots avec bien sur définition des mots / phrases.
11) Un menu pour encourager l'utilisateur : daily streak, weekly chalenge, progression global (voir une barre de progression augmenté tous les jours), et surtout avancement des chapitres
12) Un menu permettant de modifier, annotée et ajouté des mots / phrases. Peut etre faire ce menu uniquement pour les dev (donc pour moi)
13) Compte utilisateur (pas besoin de online, juste pseudo, etc ...)
14) Associé à chaque mots des catégories gramaticales (nom, verbes, ...) et des tags (mots relatif aux voyages, vie de tous les jours, shopping, etc ...). Utilisé ces tags pour créer la notion de chapitres. Une fois les mots et phrases dans la DB, je pense q'une IA peut créer les tags et catégorie avec un minimum de vérifiaction humaine. A Combiner avec idée 12.
