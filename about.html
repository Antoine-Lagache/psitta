About the developer

Hi, I'm Antoine.

I'm Antoine Lagache, a French engineering student interested in mathematics, computer science and language learning.

I study at Grenoble INP–Ensimag, and I'm currently on an academic exchange at Kobe University in Japan. I develop Psitta as an independent, open-source project alongside my studies.

Why I built Psitta

While studying Japanese, I wanted a tool that connected vocabulary practice with sentences that reuse familiar structures. Psitta grew from that idea: short study sessions, spaced repetition and a learning experience that can evolve as the project develops.

Building it is also a software engineering project. I work on the learning engine, content preparation and cross-platform app using Flutter and Dart. The code is public so others can inspect it, contribute and help improve it.

Follow the project

Psitta is still at an early stage. Feedback, bug reports and contributions are welcome.
